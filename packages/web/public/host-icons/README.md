# Host identity marks

These marks identify the third-party hosts in the illustrative Tandry conversation.
They are not Tandry branding and do not imply endorsement.

SVG source: [LobeHub Icons](https://github.com/lobehub/lobe-icons), retrieved 2026-09-19.
Files are unmodified; the monochrome Codex mark is displayed white with CSS.

- `claude-code.svg`: `packages/static-svg/icons/claudecode-color.svg`
- `codex.svg`: `packages/static-svg/icons/codex.svg`
- `chatgpt.svg`: `packages/static-svg/icons/openai.svg` (`@lobehub/icons-static-svg` 1.95.0), the mark ChatGPT uses; drawn in `currentColor`, so the install page inverts it to white
- `../hosts/grok.svg`: `packages/static-svg/icons/grok.svg` (`@lobehub/icons-static-svg` 1.95.0, retrieved 2026-09-22), the Grok mark used for Grok Build; its `currentColor` fill was changed to white so it shows on the dark theme without CSS

The source library's MIT license is included in `LICENSE`. Trademarks belong to their
respective owners. The shapes were checked against the [official Claude Code demo](https://github.com/anthropics/claude-code/blob/main/demo.gif)
and [OpenAI's Codex product imagery](https://openai.com/codex/get-started/).
