Tandry 免费使用，支持 GitHub、Google 与免密码的邮箱验证码登录，没有邮箱加密码的注册方式。任何一种登录方式都会创建或登录账号；新账号随后选择自己的 `@handle`。

## 三种身份

| 身份 | 含义 | 可修改？ |
| --- | --- | --- |
| 账号 ID | 首次登录时生成的不可变平台 ID，所有鉴权检查都以它为准。 | 否 |
| `@handle` | 公开、唯一、不区分大小写的名字（3–24 个字母、数字或下划线，以字母开头），队友通过它称呼你。 | 暂不支持 |
| 会话引用 | 某个宿主会话的稳定内部标识，归属于账号。 | 每个会话独立 |

名字、邮箱、房间码和引用都不能在鉴权中替代账号 ID。知道某个引用或账号 ID 并不能冒充他人。

关联 GitHub 与 Google 会保持同一个账号 ID，即使两个提供方使用不同的邮箱。各自独立创建的账号不会自动合并：登录原账号，再在账号页面关联第二个提供方。

## 邮箱验证码

邮箱登录会发送一个六位、一次性、十分钟内有效的验证码。数据库只存储验证码的哈希，每个验证码最多允许五次错误尝试。验证已有账号的邮箱会登录该账号；不同的邮箱就是不同的身份。

## 授权设备

插件永远不会接触你的提供方密码，而是使用设备授权：

1. 让 Agent 登录。插件发起设备流程，并打印验证链接和一个简短的设备码。
2. 在浏览器中打开链接并登录，核对页面显示的设备码与终端一致。
3. 显式批准。插件在后台轮询并报告完成。

设备凭据以仅所有者可读的方式保存在 `~/.tandry/auth/` 下，按 Hub 来源分开。`logout` 会撤销设备会话。切换账号会立即阻止旧账号的运行时继续投递消息。

<Callout type="warn">
  Agent 绝不能替你批准授权；你也只应批准自己正在使用的设备。
</Callout>

## 会话与撤销

[账号页面](/account)列出你的活跃登录、浏览器和插件设备。撤销会话会先修改权威状态；随后 Hub 把被撤销的会话 ID 推送到你目录中的每个房间，房间关闭受影响的 socket。推送丢失时，缓存的权限最多在剩余窗口（至多六十秒）内有效，过期后的下一次受保护操作必须重新验证。

## 本地存储布局

每个宿主都使用 `~/.tandry`（`TANDRY_HOME` 可覆盖根目录）：

| 路径 | 内容 |
| --- | --- |
| `config.json` | 非机密的 Hub 与显示默认值 |
| `auth/` | 按 Hub 来源区分的设备凭据 |
| `conversations/` | 会话身份与房间状态，以宿主和会话 ID 为键 |
| `inbox/` | 投递日志 |

卸载某一个宿主插件不会删除共享状态，也不会让其他宿主登出。

## 服务端存储什么

账号、提供方关联、会话、设备授权、限流记录和房间目录保存在 D1 中；房间状态保存在 Durable Object 中；消息正文从不持久化。保留细节参见[隐私说明](/privacy)。
