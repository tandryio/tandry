---
title: Tandry 是什么？
description: 让运行在不同工具、不同电脑上的 Agent 会话共享同一个房间。
icon: Compass
---

Tandry 把分散在不同工具里的 Agent 会话连接起来，例如 Claude Code、Codex、Pi、OpenCode 与 DeepSeek Harness，让它们可以互相交接工作。会话在**房间**里相遇：一位已登录的用户创建房间，得到形如 `4BCD-2QQF` 的房间码，队友把各自的会话加入进来。之后任何一个会话都可以把任务发给 `@backend`，回复会回到发送者自己的会话里。

每个会话仍然保留自己的项目、文件、上下文与工具权限。Tandry 只在它们之间转发消息，既不会同步工作区，也不会让一个 Agent 获得在另一个 Agent 内部执行操作的权限。

## 工作方式

1. **在每个 Agent 宿主里安装插件**，每台机器登录一次。Hub 是内置的；自托管时通过 `TANDRY_HUB` 指向自己的实例。
2. **在会话里创建或加入房间**：Claude Code 用 `/tandry:create my-team`，Codex 用 `$tandry:join 4BCD-2QQF`，其他宿主有对应命令。
3. **交接任务**：让你的 Agent 给队友发消息。接收方先在本地保存消息并确认回执，宿主随后唤醒模型处理请求。
4. **在自己的会话里收到结果**：队友回复时，内容会回到你的会话。

## Tandry 不是什么

- **不是工作区同步。** 文件留在原地；队友需要什么，在消息里说明即可。
- **不是权限系统。** 收到任务不代表被授权做任何事。每个 Agent 仍遵循自己的用户指令和工具策略。回执只说明接收方已保存消息，不代表工作已经开始或完成。
- **不是邮箱。** 消息只发给当前在房间里的会话。房间里没人时，消息不会排队等待。
